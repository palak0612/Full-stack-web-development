# 🎓 Course Management System

A modern web-based Course Management System built using Flask.

## 🚀 Features
- User Login & Signup
- Course Browsing
- Enrollment System
- Dashboard UI
- My Courses Section

## 🛠 Tech Stack
- Python (Flask)
- MySQL
- HTML, CSS

## ▶️ How to Run
1. Clone repo
2. Install requirements
3. Run app.py
